# TaskMate

TaskMate is a Flutter student task and deadline manager. It uses Firebase Authentication, Cloud Firestore, Provider-compatible streams, table calendar, and timezone-aware local deadline notifications.

## Prerequisites

- Flutter stable SDK
- An Android device/emulator or iOS simulator
- A Firebase project
- Xcode on macOS for iOS builds

## Firebase setup

1. Create a Firebase project in the Firebase console.
2. Enable Authentication → Sign-in method → Email/Password.
3. Create a Cloud Firestore database.
4. Register Android and iOS apps using FlutterFire CLI:
   - `dart pub global activate flutterfire_cli`
   - `flutterfire configure`
   - Select the same Firebase project and Android/iOS platforms.
5. Replace `lib/firebase_options.dart` only if FlutterFire does not generate it automatically.
6. Place Android configuration as `android/app/google-services.json` if not generated by the CLI. For iOS, place `GoogleService-Info.plist` in `ios/Runner` and complete the Xcode runner setup.
7. Deploy the included rules: `firebase deploy --only firestore:rules`.

## App icon and splash

The validated 1254×1254 source image is stored at `assets/branding/taskmate_icon.png`. Launcher icons and the native splash were generated with:

```powershell
dart run flutter_launcher_icons
dart run flutter_native_splash:create
```

Android adaptive and standard launcher assets plus iOS AppIcon assets are generated from that source. The splash uses the deep-indigo brand background and the supplied image centered.

## Android notifications

The app declares the Android POST_NOTIFICATIONS permission and an `taskmate_deadlines` notification channel. Android 13+ prompts the user through the app permission API. Android 12 or earlier normally allows notifications by default.

## iOS notifications

Open the Runner project in Xcode on macOS, enable Push Notifications capability if required for package integration, and ensure Notification Background Modes if you need background delivery. The app requests alert, badge, and sound permission at runtime and on the Notification settings control.

## Run

```powershell
flutter pub get
flutter run
```

For Android: `flutter run -d android`. For a specific Android APK: `flutter build apk`.

For iOS on macOS:

```bash
cd ios
pod install
cd ..
flutter run -d ios
flutter build ios
```

## Test flow

1. Register a new account.
2. Verify login persists after app restart.
3. Create tasks with future due times and reminders.
4. Complete, reopen, edit, and delete a task.
5. Test search and All/Pending/Completed filters.
6. Confirm calendar dates and selected-day lists use real Firestore data.
7. Sign out and verify another account cannot see another user's tasks.

No sample tasks are included in production code. Build execution requires valid Firebase platform configuration and a device/simulator.
